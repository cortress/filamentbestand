    Synchronisation

    Jede Änderung wird sofort verschlüsselt auf dem Gerät gespeichert und automatisch ins Repository übertragen. Gleichzeitige Änderungen mehrerer Personen werden zusammengeführt. Offline gemachte Änderungen werden nachgereicht.

    Team-Zugang Admin

    Für das automatische Speichern braucht das Team einen GitHub-Token (Fine-grained, nur dieses Repository, Contents: Read and write). Er wird mit dem Team-Passwort verschlüsselt im Repo abgelegt – alle, die das Passwort kennen, können dann speichern, ohne selbst einen Token zu haben.

    KI-Erkennung für Fotos optional

    Ohne Einstellung werden Lieferscheine und Etiketten lokal im Browser per Texterkennung gelesen (kostenlos, Fotos verlassen das Gerät nicht). Mit einem Claude-API-Key (console.anthropic.com) wird das Foto zur Auswertung an Anthropic gesendet – deutlich genauer, besonders bei Lieferscheinen. Der Key wird mit dem Team-Passwort verschlüsselt im Repo abgelegt.
